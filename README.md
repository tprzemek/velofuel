# VeloFuel — Smart Cycling Nutrition PWA

A mobile-first cycling nutrition Progressive Web App designed around real-world athlete habits:

- **Workout-Matched Daily Macros** — Automatically scales carbs and calories to your planned or completed rides (using riding efficiency and non-ride hours), with tomorrow's hard-ride pre-loading and on-bike fuel/fluid guidance.
- **Keep Your Home Menu (Auto-Scaled Staples)** — Define the regular meals you already cook at home and scale only the carb and protein portions to match Rest, Moderate, or Hard ride days.
- **Work Meals Without a Scale** — Describe what you ate or snap a plate photo to estimate macros with a `±%` range so your evening home dinner balances the day automatically.
- **Intervals.icu + Withings Smart Scale Sync** — Pulls your morning Withings weigh-ins, completed rides, and upcoming planned workouts directly from Intervals.icu, tracks a smoothed 7-day weight & muscle-mass trend, and supports Withings CSV import.
- **Smart Weight-Loss Mode** — Places gentle calorie cuts on Rest and Easy days while keeping Hard rides fully fueled and protein high to protect muscle and watts.

## Install on Your Phone

Open the live GitHub Pages URL (`https://tprzemek.github.io/velofuel/`):
- **iPhone (Safari):** Tap **Share → Add to Home Screen**
- **Android (Chrome):** Tap **Menu → Install App / Add to Home screen**

## Connect Intervals.icu

1. Open **Sync** inside VeloFuel.
2. Copy your personal API key from **intervals.icu → Settings → Developer Settings** (leave Athlete ID as `0`).
3. Tap **Sync Intervals.icu Now**. Your API key stays stored only in your own browser's local storage.
